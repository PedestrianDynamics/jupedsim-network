`jupedsim_network` estimates the required safe egress time (RSET) of a
building from a coarse graph of nodes and links. It depends only on
NumPy.

```
pip install git+https://github.com/PedestrianDynamics/jupedsim-network
```

- [Network model](network-model/): usage, model elements, update
  scheme, verification, comparison with EvacuatioNZ and limitations.
